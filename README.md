# Master Coast Autos V87 Android launcher

Android Custom Tab launcher for https://master-coast-autos-v87.desilvaautohub.workers.dev. It does not contain credentials or modify the website or database. Requires internet and a compatible browser. This is not a fullscreen TWA. Passkey support depends on device, browser, and Supabase configuration.

GitHub Actions builds a debug-signed test APK on pushes to main and manual runs. Open Actions > Build Android APK > latest run > Artifacts > MasterCoastAutosV87-debug-apk to download. Extract ZIP and install app-debug.apk on Android. Test authentication and finance functions before business use.
